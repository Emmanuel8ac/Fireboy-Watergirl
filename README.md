# 🔥💧 Fireboy & Watergirl 

---

## Descripción del proyecto

Este proyecto consiste en el desarrollo de una aplicación inspirada en el videojuego clásico *Fireboy & Watergirl*, enfocada en la creación de una interfaz gráfica que simula un entorno de juego cooperativo.

El objetivo es representar un sistema donde dos jugadores puedan interactuar y colaborar para resolver distintos desafíos dentro de un mismo escenario.

---

## Idea principal

El juego se basa en la cooperación entre dos personajes:

* **Fireboy**: resistente al fuego, vulnerable al agua
* **Watergirl**: resistente al agua, vulnerable al fuego

Ambos deben trabajar en conjunto para superar obstáculos y completar los niveles.

---

## Dinámica del juego

El sistema plantea una experiencia cooperativa donde los jugadores deben:

* Resolver rompecabezas
* Activar mecanismos del entorno
* Evitar peligros
* Recolectar elementos
* Llegar juntos al objetivo

Las acciones de un jugador afectan directamente al otro, por lo que la coordinación es esencial.

---

## Interacción entre jugadores

El diseño contempla un sistema multijugador donde se puede:

* Crear o unirse a una partida
* Simular conexión entre jugadores
* Coordinar acciones dentro del juego

---

## Elementos del juego 

Dentro de los escenarios se consideran elementos como:

* Botones de presión
* Palancas
* Plataformas móviles
* Puertas
* Zonas peligrosas (fuego, agua, veneno)
* Gemas coleccionables

Estos elementos permiten construir retos que requieren cooperación.

---

## Implementación actual

El proyecto se enfoca en la construcción de la **interfaz gráfica**, incluyendo:

* Pantalla principal
* Configuración de jugadores
* Pantalla de conexión (crear/unirse)
* Pantalla de juego
* Pantalla de puntuaciones

---

## Tecnologías utilizadas

* Python 3
* PySide6

---

## Ejecución del proyecto


1. Entrar a la carpeta:

```bash
cd code
```

2. Instalar dependencias:

```bash
pip install PySide6
```

3. Ejecutar:

```bash
python main.py
```
